Questions, answered

Do I need a CSS framework or build step?

No. Link one stylesheet and, if you want the interactive parts, one script. It works in any framework or in plain HTML.

Can I use it in client projects?

The core kit is MIT licensed, so yes. Premium blocks and site templates can be used in client work with a Team licence.

How do themes work?

Every colour, radius and shadow is a CSS variable. Pick a preset or set your own brand colour; components and charts follow automatically.

Is it accessible?

State is expressed with ARIA attributes, focus rings are always visible, motion respects your system setting and every chart has a hidden data table.

What if I need help?

Pro and Team licences include email support. Team adds priority support with a one-working-day response.
