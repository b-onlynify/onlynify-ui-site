How we made invoices ten times faster

VK
Vikram KumarStaff engineer

Generating a PDF used to take 1.8 seconds on a busy day. Customers noticed. Here is how we brought it under 200 milliseconds without changing a single template.

Measure before you guess

We added timing around every step and found most of the time went to loading fonts on each request, not drawing the page.

The slowest part of the system was the part nobody thought about.
pdf.ts
// Load fonts once, reuse for every invoice
const fonts = await loadFonts(["Inter", "Noto Sans"]);
export function renderInvoice(inv) {
  return draw(inv, { fonts, dpi: 144 });
}

Cache what never changes

Logos, fonts and tax tables now live in memory. Only the numbers are drawn per request.
